# 美股版投研 Agent（us-ir-agent）

> 2026-10-25。把 ir-agent（A 股）的架构复制到一个独立仓库，模型架构不变，替换数据接口，
> 并按美股调整财报口径、DCF 与相对估值等方法论细节。
>
> 本文暂存于 `谢海量作品集/us-ir-agent-design/`；新仓库建好后作为第一个提交放进
> `docs/design/`。

## 背景

ir-agent 已经在 A 股上跑通四次调用、三道闸门的完整流程：事实账本 + 时点守卫、占位符契约、
撰写者 + 审核者、两轮多空辩论、三表 DCF、蒙特卡洛、相对估值（可比法 + 全行业回归）。
这些机制大多与市场无关；与 A 股绑定的主要是**数据源**和**会计口径**两层。

## 用户决定（2026-10-25）

1. **独立仓库**：复制现有架构到新仓库修改，A 股仓库全程不动，避免不可逆的错误改动。
2. **模型架构不变**：撰写者 + 审核者、两轮辩论、三道闸门、占位符契约、事实账本全部保留。
3. **用途**：放进作品集公开展示，同时自己研究美股时实际使用。
4. **研报语言用中文**：撰写者、审核者提示词与数字审计规则基本原样复用。
5. **数据尽量全，接受程序依赖免费档 key**；**不付费**。
6. **接受 defeatbeta 这类「转存 Yahoo 数据、仅限研究用途」的来源**，作为二手来源使用。
7. 美股方法论按下文「四」的默认做法（用户已逐条认可）。
8. 试跑公司：苹果、英伟达、Costco、卡特彼勒。
9. **DCF 引擎改用本地现成的 `us-dcf`**（2026-09-11 建，约 4400 行，EDGAR + FMP，自带变异测试），
   不再改造 `ashare-dcf`。经营租赁、债务成本、β 三处**按 `us-dcf` 的现有做法**（见「四」）。
10. GitHub 仓库 `928460495/us-ir-agent` 已由用户建好（空仓库）。

## 设计者的决定（可推翻）

- 本地目录 **`谢海量作品集/us-ir-agent`**；用本地 `git clone` 复制 ir-agent 并**保留 git 历史**，
  远端改指向用户已建的 `928460495/us-ir-agent`。以后 A 股版修了共用的坑可以 `git cherry-pick`
  搬过来。
- **Python 包名保持 `ir_agent` 不改**：全仓改名会让每个文件都变成「新文件」，cherry-pick
  从此失效。
- **DCF 引擎**：删除仓库内的 `ashare-dcf/`，把本地 `谢海量作品集/us-dcf/`（非 git 仓库）复制进来
  作为 `us-dcf/`，单独一个提交，提交说明写明来源。
- **不保留双市场代码**：A 股专用的数据适配器在美股替代件落地、测试通过后删除，不做市场开关。
- GitHub 远端仓库**暂不创建**；需要公开时再单独确认（对外动作）。

## 二、数据层

| 数据 | 主源 | 补充 / 交叉核对 | 说明 |
|---|---|---|---|
| 三表（XBRL） | **SEC EDGAR**（`data.sec.gov` 的 companyfacts） | FMP 免费档 | 免费、无 key；**直接调接口并落原始快照**，不用 edgartools 这类封装库（拿不到原始响应）。edgartools 只作 XBRL 科目映射的参考 |
| 公告与原文 | EDGAR：10-K、10-Q、8-K、DEF 14A | — | 10-K 抽 Item 1（业务）、1A（风险因素）、7（MD&A）、7A |
| 总股本 | EDGAR 封面字段 `dei:EntityCommonStockSharesOutstanding` | FMP profile | 稀释股数取利润表的加权稀释股数 |
| 管理层表述 | **8-K 业绩新闻稿（EX-99.1）** | **defeatbeta 电话会纪要**（二手） | 免费档拿不到 FMP 纪要 |
| 本司行情、市值、β 原始序列 | FMP 免费档 | Tiingo | FMP 不在范围内时由 Tiingo 兜底 |
| 全行业同行行情 | **Tiingo 日终** | defeatbeta 行情表 | FMP 免费档无批量行情、标的范围受限 |
| 一致预期 | FMP 免费档 `analyst-estimates` | — | 不在范围内就写「不可用」 |
| 行业分类 | EDGAR `submissions` 的 SIC → **Fama-French 49 行业** | IBKR connector（仅开发时人工参考） | 映射文件来自 Ken French Data Library 的「Download industry definitions」 |
| 宏观 | **FRED** | — | 用 ALFRED 历史版本取「当时公布的初值」 |
| 利率 | FRED `DGS10` 等 | defeatbeta 国债收益率表 | — |
| ERP | **Damodaran 每月隐含 ERP**（NYU Stern 网站下载） | — | 每月初更新 |

**全行业样本怎么取**（回归要几十到几百家）：
- 公司名单：SEC 的 `company_tickers_exchange.json`（全部有代码的上市公司及交易所）＋ 批量
  `submissions.zip` 里的 SIC，映射到 FF49 行业。
- 横截面财务数：用 EDGAR 的 **XBRL frames 接口**——一次请求返回**所有公司**某个科目在某一期的
  值（例如全部公司 2025 年第二季度的营收），不必逐家下载 companyfacts。
- 行情：Tiingo 逐家取日终价。

**访问规范**：SEC 要求请求头声明身份与联系邮箱，上限每秒 10 次（按每秒 ≤ 9 次限流）；
联系邮箱从环境变量 `SEC_USER_AGENT` 读取，**不写进代码**。访客需注册三个免费 key：
`FMP_API_KEY`、`TIINGO_API_KEY`、`FRED_API_KEY`。

**交叉核对一律三态**：一致 / 不一致 / **不可用**。FMP 返回 402 时报「核对不可用」，不得因
「没发现不一致」报「全部一致」（假绿灯）。

**二手来源的边界**：defeatbeta（数据转存自 Yahoo Finance、Nasdaq，仅限研究用途，更新时间
不固定、无披露日）只能**进语料库**或**做交叉核对**，**不能作为账本数字的主源**。仓库只公开
代码，`out/`、`snapshots/` 继续忽略。

## 三、期间与时点

1. **披露日**取 EDGAR `companyfacts` 每条事实自带的申报日（`filed`，精确到日），作为事实的
   「可知时点」。`acceptanceDateTime` 只在 `submissions` 的申报清单里有，与单条事实对不上，
   不采用。
2. **命令行的 `--year` 指财年**：`python -m ir_agent AAPL --year 2025` 指苹果 FY2025
   （截止 2025-09-27），不是自然年 2025。股票用代码（ticker），内部再换成 SEC 的 CIK。
   **财年**：期间标签改为「财年 + 截止日」，例如苹果 FY2025 截止于 2025-09-27。同业对齐、
   TTM 截止点一律按**报告期末日期**判断，不用「2026H1」这类标签。
3. **季报**：10-Q 利润表同时给出当季三个月与年初至今两组数，**直接取当季三个月**；第四季
   = 全年 − 前三季累计。现金流量表仍是年初至今累计，需要拆分。
4. **折旧摊销每季披露**：EBITDA 的 TTM 可截到任意一季，A 股「只到中报 / 年报」的限制取消。
5. **重述**：10-K/A、10-Q/A 作为同一事实的新版本入账，时点守卫照常生效。
6. **宏观**：FRED 的 ALFRED 历史版本让宏观数据也满足时点守卫（A 股版只能按「统计期末 + 保守
   滞后」推算）。

## 四、方法论

### 1. 财报口径（US GAAP 与中国准则的差异）

| 项目 | A 股做法 | 美股做法 | 为什么 |
|---|---|---|---|
| **EBIT** | 营业利润**加回利息**（中国准则把财务费用放在营业总成本里） | **直接用营业利润（Operating Income），不加回利息** | US GAAP 的营业利润本来就在利息之前，再加回会把利息算两遍。DOL、ROIC、Altman Z、EBITDA 都受影响 |
| 归母净利润 | 归属于母公司 | `NetIncomeLoss`（已是归母） | 全口径是 `ProfitLoss`，标签别取错 |
| 少数股东权益 | 少数股东权益 | 非控制性权益（NCI） | 口径相同 |
| 非 GAAP 指标 | — | 公司公布的「调整后」口径单独登记、标明来源，账本主数用 GAAP | 调整口径各家不一 |
| XBRL 科目 | 东财科目名映射 | 同一概念多种标签（如营收至少三四种写法），建映射表并给候选 | 与 A 股科目名映射同一类工作 |

### 2. DCF

| 项目 | 做法 |
|---|---|
| **股权激励费用（SBC）** | **不加回**，按 Damodaran 的观点当作真实成本；每股价值用**稀释后股数**（期权、RSU 按库存股法） |
| **经营租赁（ASC 842）** | **两边都不算**：营业利润已扣过租金，租赁负债**不计入净负债**（否则重复扣），金额另列备查。相对估值的 EV/EBITDA 同一口径 |
| 股票回购 | 不用股利折现；预测期股数反映回购 |
| 风险溢价 ERP | Damodaran 每月隐含 ERP |
| β | **五年月度**回归，Blume 调整（`us-dcf` 现有做法） |
| 债务成本 kd | **Altman Z → 合成评级 → FRED 实时 ICE BofA 信用利差**；评级为可编辑输入，知道实际评级可直接填（`us-dcf` 现有做法，出自 FINC6021） |
| ERP 地域调整 | 按收入地域用 Damodaran 国家风险溢价加权（`us-dcf` 现有做法） |
| 终值税率 | 边际税率约 25%（联邦 21% + 州税） |
| 永续增长率 | 不超过十年期国债收益率 |
| 类债务项目 | 养老金缺口、优先股在 EV → 股权价值的桥接中扣减 |
| 可抵扣亏损 NOL | 作为资产单列 |
| 金额单位 | 亿美元、万美元 |

**`us-dcf` 需要补的 4 项对接能力**（它建于 ir-agent 给 `ashare-dcf` 加这些能力之前）：
1. 「1b_驱动分解」页：门③ 人批准的分解式写进工作簿，改一个因子带动整条估值链；
2. 按判断项写入悲观 / 中性 / 乐观三档（`growth_scen` / `gm_scen`）；
3. 首年按季度锚定（已公布季度用实际，其余按年初至今同比外推）；
4. `verify_all_scenarios(..., values=)` 带回三档每股价值（足球场图要用）。

另外，它目前自己取数；要加一个由 ir-agent **事实账本供数**的入口（与 `ashare_calibrate.calibrate(..., stmts=)`
同一做法），保证分析层与估值层用同一套数字。

### 3. 相对估值

- PE 同时给 **TTM** 与 **NTM（未来十二个月）**；NTM 用 FMP 一致预期，拿不到只给 TTM。
  NTM EPS 按时间加权：本财年剩余月份占比 × 本财年预期 + 其余 × 下一财年预期。
- 亏损公司加用 **EV/Sales**。
- 回归样本为本司所在 **Fama-French 49 行业**的全体公司；规则沿用 A 股版（四条「不可用」判据、
  P10–P90 预测区间、剔除本司与两端 5%）。
- 可比名单：同一 FF49 行业内按市值就近选取，沿用 A 股版做法。

### 4. 盈余质量

- 保留 **Altman Z**；非制造业改用 **Z'' 版本**。
- 新增 **Beneish M-score**（识别财务操纵）与 **Sloan 应计指标**（应计利润占比）。

### 5. 宏观与行业

- 商业周期四阶段框架（Fidelity）本身源于美国市场，直接适用。
- 指标改用 FRED：CPI、PCE、PPI、GDP、失业率、非农、工业产出、零售销售、新屋开工、
  密歇根消费者信心、10Y−2Y 期限利差、信用利差。**ISM PMI、世界大型企业联合会领先指标
  为付费数据，不用**。
- 行业生命周期、集中度、杠杆等算法沿用；样本换成 FF49 行业。

## 六、风险与已知限制

- **FMP 免费档标的范围规则不公开**：同一只股票今天能查、明天未必，交叉核对必须容忍「不可用」。
- **defeatbeta 无披露日**：电话会纪要只能当二手语料，不进时点守卫。
- **SIC 只有当前值**：EDGAR 给的是公司现在的 SIC，回测时可能与历史行业不符。
- **免费档授权限于个人或研究用途**：作品集只公开代码与方法，不公开数据。
- **Tiingo 免费档频次上限未核实**：阶段 1 实测后确定限流参数。

## 七、测试要点

- 每个新数据适配器：用录制的真实响应做离线固件，覆盖成功、402、缺字段三种情况。
- 期间模型：苹果 9 月财年、Costco 非自然年的 TTM 与同业对齐。
- **EBIT 不加回利息**：同一组数据在 A 股口径与美股口径下结果不同的回归测试。
- SBC、租赁、稀释股数：DCF 引擎逐项的单元测试与工作簿逐格复算。
- 三态交叉核对：402 时报「不可用」，不报「一致」。

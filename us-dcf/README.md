# 美股 DCF 通用模板（us-dcf）

输入一个美股代码，生成一份**全公式、可编辑**的三表 + DCF Excel 模型。

```bash
export SEC_USER_AGENT="Your Name your@email"   # SEC 要求写明身份；只从环境变量读取
python3 us_dcf.py AAPL
python3 us_dcf.py NVDA --years 8 --out ~/Desktop
```

> **与 `ashare-dcf` 完全独立**：不 import、不修改 A 股包的任何文件。
> 两者的会计准则、数据源、货币、信用利差口径都不同，刻意不共用代码。

## US GAAP 相对 CAS 的处理

| 项 | 做法 | 理由 |
|---|---|---|
| **EBIT** | 直接取 `OperatingIncomeLoss` | US GAAP 的 Operating Income 本来就在利息之前，不必像 CAS 那样用「营业利润 + 财务费用」倒推 |
| **SBC** | **不加回**（默认）| Damodaran：SBC 是真实成本，只是用「以股易工」规避了现金流。SBC 已含在报表 R&D/SG&A 内，什么都不做即已费用化 |
| **SBC 与股数** | **绑在同一开关上** | 既然现金流里罚过一次，就不该再摊薄股数。开关置 1 则两件事同时切换，无法只做一半 |
| **回购** | 逐年滚动股数 | 美股常态（AAPL 五年回购 ≈ 营收 22%）|
| **经营租赁** | **不计入净负债** | ASC 842 下经营租赁费用仍在营业费用内，Operating Income 已扣过租金；再计入即重复扣。租赁负债金额另列备查 |
| **其他经营损益** | 残差项 | 令重建的经营利润**精确**等于报表 Operating Income，重组/减值/和解等不会凭空消失 |
| **终值税率** | 25%（联邦 21% + 州税的合并边际税率，见下文「终值税率 21% → 25%」）| 永续期不应假设税收优惠永存 |
| **财年** | 支持非 12-31 与 52/53 周财年 | AAPL 09-26、MSFT 06-30、NVDA 01-31 各不相同，滚动年数按实际财年末计算 |
| **非经营资产** | 长期有价证券 + 权益法投资 | 短期投资已在净负债中扣除，不重复 |

## FINC6021 方法的落点

方法来自 University of Sydney FINC6021 Corporate Valuation（S2 2025）与
Titman & Martin, *Valuation*, 3rd ed.，实现于 `valuation_lib.py`。

### 1. 债务成本 kd：Altman Z → 合成评级 → 实时利差（Ch.4）

```
kd = 无风险利率 + 国家违约利差 + 公司违约利差
Z  = 1.2A + 1.4B + 3.3C + 0.6D + 1.0E
```

评级阈值取讲义 p.15 表中相邻评级均值的中点；利差用 FRED 的 ICE BofA OAS 实时序列
（讲义用的是 2017 年静态曲线图）。

**但这套方法在大市值公司身上有明确边界，模型会把边界显示出来**：

| | Z | **D 项占比** | 合成评级 | 实际 S&P |
|---|---|---|---|---|
| MSFT | 8.71 | 80% | AAA | **AAA** ✅ |
| AAPL | 11.94 | 81% | AAA | **AA+** |
| GOOGL | 15.84 | 85% | AAA | **AA+** |
| NVDA | 69.99 | **93%** | AAA | **AA** |

D 项是「股权市值 / 总负债」。NVDA 市值是总负债的 168 倍，Z=70 里 93% 只是这一个比值 ——
Altman 1968 年标定于制造业样本，彼时市值与负债同量级。**Z 高不等于评级准**，
且实测系统性高估 1–2 个子级。因此：

- 「信用评级」是**可编辑输入**，Z 推导值只作默认。知道实际评级就直接填。
- 模型另给 **`kd → WACC` 敏感度**：AAPL Wd 2.10% 时 kd 变 77bp 只让 WACC 动 **1.32bp**，
  NVDA（Wd 0.16%）只动 **0.10bp**。**这一格值不值得较真，取决于 Wd，而不取决于 Z 算得多精。**

### 2. 可持续增长率交叉校验（公式表）

`g = (1 − 派息率) × ROE`，与模型终值用的 `g = 再投资率 × ROIC` 互为对照。

**但这条公式对长期大额回购的公司会失效**，模型会先判定再用：

| | ROE | g_sustainable | 可用 |
|---|---|---|---|
| AAPL | 171% | 145% | ❌ |
| NVDA | 101% | 100% | ❌ |
| MSFT | 34.0% | 26.3% | ✅ |
| GOOGL | 35.7% | 33.9% | ✅ |

库存股按**市价**冲减权益，AAPL 账面权益只剩 $737 亿（营收 $4,162 亿），
ROE 171% 不代表任何可再投资的资本回报。判定条件：ROE > 50% 或 权益/资产 < 15%。

### 3. 资本结构漂移诊断（Ch.4 三条估计原则之三）

WACC 假定资本结构恒定，但以现金为 plug 的三表模型会让 D/(D+E) 逐年漂移。
`5_DCF` 第六节逐年列出模型内含权重与 WACC 假设权重的差。

### 4. Plug 的显式声明（Ch.6）

课程原话：plug 是财务模型中**最重要的财务政策变量**，不是技术细节。
本模型用「现金 + 循环贷」，并在假设页第七节红字写明这意味着资本结构会漂移。

### 5. 退出倍数交叉验证（Ch.8）

`5_DCF` 第五节给出模型隐含的退出 EV/EBITDA、退出 P/E，以及理论倍数 `(1+g)/(WACC−g)`。
课程结论：**倍数差异不是噪音，它编码了增长与风险的差异。**

### 6. 盈亏平衡敏感性（Ch.3 讲义 p.22–25）→ `6_Breakeven`

课程问「令 NPV = 0 的临界值」；股票估值的对应问题是**「令每股内在价值 = 现价 的临界值」**。

**这与龙卷风图问的不是同一件事**：

```
龙卷风   = 在我假设的不确定性范围内，这个变量能让价值波动多少   →【离散度】
盈亏平衡 = 我要错到什么程度，结论才会翻转                    →【脆弱度】
```

一个变量可以龙卷风条很长但临界值很远（结论稳健），也可以条很短但临界值近在咫尺（结论脆弱）。

13 个驱动因子逐个二分求解，按 |偏离%| 升序排列，<10% 标红（极脆弱）、<25% 标黄（关键）。
无解的变量会给出**端点能达到的最高值**，明确区分「求解失败」与「真的够不着」。

**实测 MSFT（$295.76 vs 现价 $487.01）**：

| 驱动因子 | 期望值 | 临界值 | 偏离 |
|---|---|---|---|
| 股权风险溢价 ERP | 5.00% | 2.16% | −56.7% |
| Beta → Ke → WACC | 1.100 | 0.476 | −56.7% |
| 营收增速（全期均值）| 10.14% | 23.30% | +129.7% |
| 永续增长率 g | 2.50% | 6.50% | +159.8% |
| 毛利率 | 68.84% | **无解** | 区间 [1%, 95%] 内最高只到 $472 |
| 资本开支/营收 | 25.33% | **无解** | 降到 0 也只到 $356 |
| 有效所得税率 | 18.42% | **无解** | 降到 0 也只到 $316 |

结论很清楚：**只有折现率能单独把估值推到现价，没有任何经营变量做得到。**
市场价隐含的不是更好的经营，而是明显更低的折现率。

#### 两个实现上的坑

**① g 的搜索区间必须按公司动态算。** 固定用宽区间 (−30%, +90%) 时，
两端都会触发终值降级 → 函数被压平成同一个常数（实测 MSFT 两端都是 $251.3），
二分永远不变号，看起来像「g 无解」，其实是区间选错了。
正确区间是 `(−5%, min(WACC, ROIC) × 0.98)`。

**② 折旧率的临界值没有经济含义。** 本模型的 EBIT 由毛利率与费用率驱动，
折旧率**只进 FCFF 加回与 PP&E 滚动，不进 EBIT** —— 调高折旧率会凭空抬高 FCFF。
该行保留但已在「说明」列标注，不要据此决策。

### 7. 经营杠杆度 DOL（Ch.8 公式表）

`DOL = 1 + [FC(1−t) − Dep×t] / OCF`。固定成本占比越高 → 营业利润对收入越敏感
→ 风险越高 → 理应用更低的倍数。

## 终值降级保护

`ROIC ≤ WACC`、`投入资本 ≤ 0`、或 `再投资率 g/ROIC` 越界时，
Gordon 式的 `(1 − g/ROIC)` 会失真甚至变号 → **降级为无增长永续 `TV = NOPAT / WACC`**。

**AAPL 必然触发**：DPO 114 天远长于 DSO 31 天，营运资本深度为负，
投入资本 = NWC + PP&E = **−$82 亿**，ROIC 算出来是 −1544%。
这不是 bug，是苹果商业模式的真实特征 —— 但 Gordon 公式在这里没有意义，
所以模型退回不含增长的永续，并在输出里明确提示。

## 工作簿结构

| 页签 | 内容 |
|---|---|
| `1_Assumptions` | 情景开关、判断项（黄底）、自动校准假设、期初余额、DCF 参数、股本与融资、**方法诊断** |
| `2_Income` | 历史实际（斜体静态）+ 公式预测，含 SBC 备查行与滚动股数 |
| `3_Balance` | 同上，含 ★平衡校验、净负债、NWC |
| `4_CashFlow` | 含 SBC 加回、回购、增发、循环贷、股数滚动、FCF、FCFF |
| `5_DCF` | WACC、FCFF 现值、**带降级保护的终值**、EV→每股、退出倍数交叉验证、**资本结构漂移诊断**、敏感性矩阵 |
| `6_Breakeven` | **盈亏平衡敏感性**：令内在价值 = 现价的临界值与偏离%，按脆弱度排序 |

颜色约定：**蓝色 = 可编辑输入**，黑色 = 公式，绿色 = 跨表链接，
**黄底 = 判断项**（模板不外推，三档初始同值，请自行拉开），橙底 = 校验格。

## 默认增速路径

**从最近一年实际增速线性衰减至永续增速**，这是**起点**不是预测。

A 股版用「历史均值 × 全期不变」，对中国工业股够用；套到美股高成长股上会失控 ——
NVDA 近 4 年增速均值约 102%，平推 5 年后营收会到 **$7.2 万亿**，
这个数字不是保守也不是激进，只是没有意义。

课程 Ch.6 的立场是收入预测要**自上而下**（市场规模 × 份额）或**自下而上**（产品线加总），
任何机械外推都只是占位符。

## 2026-09-11 重新设计：数据层去 plug 化 + 投入资本口径重建

上一版对 AAPL 给出 **每股 $91.59 / 终值 ROIC −1544.5% / 终值降级**，对 GOOGL 的固定资产给出 **0**。
根因两条，都已修掉。

### 🔴 缺陷一：平衡校验是假绿灯

```
GOOGL FY2025 固定资产净额 = 0     实际 $246,597 mn
★ 平衡校验 = 0.0                  ← 全绿
```

Alphabet 自 FY2025 起把 PP&E 换成含融资租赁使用权的标签。
**2,466 亿美元被「其他非流动资产」倒挤吸收，恒等式照样成立** ——
只要缺失科目由残差补上，平衡校验就从结构上丧失检错能力。

**修法**：关键科目（营收/营业成本/经营利润/净利润/现金/PP&E/资产总计/负债合计/归母权益）
任一期缺失 → **硬失败，拒绝出模型**，并告知该公司实际用的标签。

护栏设计走过两次弯路，都记在代码注释里：
1. 「倒挤值 vs 申报的『其他』标签」→ **4 家全部误报**。倒挤项本来就该含非贸易应收（AAPL $328亿）、
   递延收入（MSFT $730亿）、非上市股权（GOOGL $641亿），它们是真实余额。
2. 「比重年度跳变」→ **NVDA 误报**。它 FY2026 营收 130→216B，资产负债表是真的扩张了。

最终：硬失败只归 `assert_complete`（唯一可确证的错误），倒挤异动降级为警告交人判断。

### 🔴 缺陷二：投入资本口径对美股大盘不成立

`IC = 营运资本 + 固定资产` 是 A 股版口径。美股龙头营运资本为负：

| | 营运资本 | 旧 IC | 旧 ROIC | 新 IC | 新 ROIC（申报） | 新 ROIC（研发资本化） |
|---|---|---|---|---|---|---|
| AAPL | −52,042 | **−2,208** | **−4760%** | 39,970 | 272.5% | **82.2%** |
| GOOGL | −21,554 | −21,554 | −473% | 270,816 | 40.2% | **28.6%** |
| MSFT | −28,731 | 284,345 | 43% | 369,490 | 34.3% | **29.0%** |
| NVDA | 83,836 | 94,219 | 109% | 134,729 | 83.8% | **65.3%** |

### 6_Engine 敏感性引擎

每行 = 一次完整的 N 年 FCFF 重算，网格里每个格子就是一行。

可行的前提：`FCFF = EBIT(1−t) + 折旧 + 摊销 − 资本开支 − ΔNWC`，而 US GAAP 的
`OperatingIncomeLoss` 本就在利息之前 —— **FCFF 与现金余额、循环贷 plug 完全无关**，
所以能在单行内闭合算完整个模型。

每年 11 列（营收/成本/EBIT/折旧/资本开支/期末固资/摊销/商誉无形/**研发资本**/NWC/FCFF）
+ 15 列汇总（PV/终值IC/ROIC/再投资率/降级/NOPAT/TF/TV/PVTV/EV0/EV/全体权益/少数股东/归母/每股）。
研发资本逐年滚动，终值 IC 与主模型口径完全一致。

四个模块贴在「5_DCF」下方：

| 模块 | 行 | 列 |
|---|---|---|
| A | 营收增速 Δ | 永续 g |
| B | 毛利率 Δ | 永续 g |
| C | 营收增速 Δ | 毛利率 Δ |
| D | WACC 偏移 | 毛利率 Δ |

**中心格自检**：每个模块的中心格（Δ=0、g 与 WACC 取生效值）必须逐位复现主模型的每股价值。
实测差 **4.3e-14**。该断言已接进 `us_verify` —— 引擎是独立的一条计算路径，

### 7_Ratios 财务比率 + 杜邦 + 6 张图

七组比率，全部活公式：盈利能力（含 **SBC/营收**）、营运效率（含 **CCC**）、
偿债与资本结构、现金流质量（含 **回购/营收**）、成长性、杜邦三因子、杜邦五因子。

美股特有的三行：**SBC / 营收**、**回购 / 营收**、**ROE 失真提示**
（回购大户账面权益被冲小，AAPL 的 ROE 达 171%，这类公司应以 ROIC 为锚）。

ROIC 用「生效投入资本」（含研发资本），与 DCF 终值同口径；并单列
**★ 价值利差 ROIC − WACC**。

图表沿用卖方研究报告版式（深红/卡其/藏蓝、标题左对齐、图例置底、仅浅色横向网格）：
营收与净利双轴图、盈利能力趋势（含 SBC 占比）、ROIC vs WACC、杜邦倍数项、
现金转换周期、资本返还与股份支付。

**杜邦恒等式硬断言**：三因子与五因子连乘必须等于直接算出的 ROE，已接进 `us_verify`。

## 补齐三个页签（二）：蒙特卡洛

`9_MonteCarlo`。计算在 Python（向量化 numpy），参数存在 Excel 页里可编辑，


### 为什么模拟只重算 FCFF 链

因为 US GAAP 的 `OperatingIncomeLoss` 在利息之前，**FCFF 与现金余额、循环贷、股数全都无关** ——
那些环节根本不进入模拟。这与 `6_Engine` 能在单行内闭合是同一个性质。

### 随机变量

| 变量 | 处理 |
|---|---|
| 营收增速 Δ、毛利率 Δ | Cholesky 注入历史相关系数；**路径平移与逐年扰动都带相关性** |
| Beta → Ke → WACC | 抽 Beta 比直接抽 WACC 更有经济含义 |
| 永续增长率 g | 逐路径强制 `g ≤ WACC − 间距`，避免终值公式退化 |
| 资本开支率 Δ | 纳入龙卷风归因 |
| ~~有效税率~~ | **默认不随机化**（标准差置 0），固定为报告值 |
| ~~SBC~~ | **刻意不单列** —— 默认（Damodaran）口径下它已含在报告的 R&D/SG&A 里，也就是已含在 EBIT 里，再抽一次等于重复计价 |

方差分解沿用 `σ_shift² + σ_year² = σ²`（持续性占 25% 方差）；截尾用**拒绝重抽**而非 `np.clip`
—— clip 会把越界样本堆在边界两点形成点质量，恰好扭曲最需要准确的尾部。

研发资本在模拟里逐年滚动，终值 IC 与主模型口径一致。

### 硬断言：零方差必须复现确定性模型

所有标准差置 0 后，MC 引擎必须复现 `5_DCF` 的每股价值，**不一致就抛 AssertionError**。

实测：AAPL 差 **2.8e-14**、MSFT **0.0**、NVDA **0.0**。

变异测试（确认断言不是摆设）：

| 变异 | 结果 |
|---|---|
| FCFF 漏掉无形摊销 | ✅ 断言触发（156.30 vs 156.84，差 5.4e-01） |

## 中期锚定（2026-09-11）—— 不要在已知事实面前继续猜

### 问题

年报期末可能已过去近一年，其后的每个季度都是**已成事实**，而模型把那一年整个当成纯预测。

```
AAPL  年报期末 2025-09-27，距今 349 天
      年报后已披露 3 个季度，合计营收 $364,357M = 基数年的 88%
      模型用了其中的：0

      模型 FY2026E 增速假设  +6.43%
      实际前三季同比         +16.15%
      模型 FY2026E 营收       442,920
      按季节性反推            478,016    低估 $350.9 亿（7.9%）
```

**它不会以任何形式报错** —— 三表平衡、199 格复算、三档情景、golden 基线全绿。
因为所有校验检的都是「内部自洽」，而这条错在「输入过时」。

### 做法

`1_Assumptions` 新增第三节。首个预测年的**生效增速/毛利率**由已披露季度反推：

```
隐含全年营收 = 已披露期营收 ÷ 历史同期占全年比重
隐含全年成本 = 已披露期成本 + (隐含全年营收 − 已披露期营收) × (1 − 剩余期毛利率)
生效增速     = IF(锚定=1, 隐含全年营收/基期营收 − 1, CHOOSE(情景,...) + Δ)
```

锚定分支写在**生效值列**里，只引用假设页单元格，不引用利润表 —— 避免结构性循环引用。
开启时上方三档输入置灰并标红「本行输入不生效」。

与 A 股版的差别：A 股中期报告是**累计**数，美股 10-Q 是**单季**数，所以按单季求和。

### 🔴 一个必须加的护栏：占比法什么时候会骗人

占比法假设**年内形状稳定**。对高速增长的公司它会失效 —— 前几个季度占比被年内增长压低，
反推等于**在外推增长率**，恰是锚定本想避免的事。

| | 季数 | 占比 | σ | 历史同期占比 | 默认开关 |
|---|---|---|---|---|---|
| AAPL | 3 | 76.22% | **0.70pp** | 77.1/76.6/75.7/75.4% | **1（开）** |
| GOOGL | 2 | 47.30% | 0.86pp | 48.7/47.0/47.2/46.3% | 1（开） |
| AMZN | 2 | 45.64% | 0.41pp | 46.2/45.5/45.7/45.1% | 1（开） |
| TSLA | 2 | 46.42% | 2.56pp | — | 1（开） |
| **NVDA** | 2 | 43.65% | **7.73pp** | **55.6/34.0/43.0/42.0%** | **0（关）** |

NVDA 的「前两季占比」根本不是季节性，是被年内高速增长主导的。
**σ > 3pp 时开关默认置 0**，并在注释里说明原因，交给使用者判断。

同时并列展示**第二口径**：同期同比法（已披露期同比增速 × 上年全年）。
两法实测吻合在 1–5% 内（NVDA 也只差 3.8%），差得远就说明这一年不好锚。

| | 占比法 | 同比法 | 差 |
|---|---|---|---|
| AAPL | 478,016 | 483,371 | +1.1% |

| GOOGL | 485,570 | 495,699 | +2.1% |

## 终值税率与地域加权 ERP（2026-09-11）

### 终值税率 21% → 25%

**21% 是联邦法定税率，不是边际税率。** 州税可在联邦税前扣除，所以合并边际税率是：

```
21%（联邦） + 5%（州加权） × (1 − 21%) = 24.95% ≈ 25%
```

Damodaran 的美国边际税率数据集用的也是 25%。用 21% 会让终值 NOPAT 高估 **5.06%**，
而终值占 EV 约 67–75%。明确期仍用历史有效税率（这是税收优惠的真实体现），
只有**永续期**不应假设优惠永存。

### 收入地域加权 ERP

AAPL 国际收入 57%、GOOGL 52%、MSFT 48.5%，全部按**美国** ERP 折现，
等于假设在中国赚的钱和在美国赚的钱风险一样。

**口径**（Damodaran 2025 年起的新惯例 —— 他已不再把美国当成熟市场基准，
因为美国不再是 Aaa，自身带 0.23% 的国别风险溢价）：

```
成熟市场基准 = 标普500隐含ERP − 美国CRP  = 4.09% − 0.23% = 3.86%
地域加权 ERP = 成熟市场基准 + Σ(收入权重 × 该国/区域 CRP)
```

纯美国收入时自动还原为标普隐含 ERP —— 与原行为无缝衔接。

数据：分地域收入取自 FMP `revenue-geographic-segmentation`（**免费档可用**，
SEC `companyfacts` 不含维度数据所以取不到分部）；国别 CRP 取自
Damodaran `ctryprem.xlsx`（157 国，缓存 30 天）。

| | 地域结构 | 加权 ERP | vs 纯美国 |
|---|---|---|---|
| AAPL | 美洲 42.9% / 欧洲 26.7% / 大中华 15.5% / 日本 6.9% / 其他亚太 8.1% | **4.61%** | +0.52pp |
| MSFT | 美国 51.5% / 非美 48.5% | **5.00%** | +0.91pp |
| GOOGL | 美国 48.2% / EMEA 29.1% / 亚太 16.8% / 美洲除美 5.9% | **4.92%** | +0.83pp |
| NVDA | 美国 69.3% / 台湾 19.6% / 中国 9.1% / 其他美洲 2.0% | **4.34%** | +0.25pp |

**做成活公式而不是静态数字**：假设页列出每个地域的权重与 CRP（都可编辑），
加权 CRP 与 ERP 是公式，改权重或 CRP 则 WACC 全链路自动跟着走。
映射本身是判断项 —— 必须可审计、可覆盖。另有「★ 权重合计应为 100%」校验格。

#### 🔴 一个被自己抓到的错

「非美国」这个桶最初用的是**各区域 CRP 的简单平均**（3.52%），
把非洲和西欧等权重了 —— 而 MSFT 的非美收入绝大部分在西欧与发达亚洲。
这让 MSFT 的 ERP 虚高 **1.6pp**。改成**全球 GDP 加权（剔除美国）= 2.11%** 后，
MSFT 的调整从 +1.60pp 修正到 **+0.91pp**。

> 对只披露「美国 / 非美国」两档的公司，这个调整天然是粗的 —— 表里会照实显示映射结果。

### 效果分解（AAPL）

| | 每股 | WACC |
|---|---|---|
| 改前（税 21% + 纯美国 ERP） | $134.43 | 9.33% |
| 仅改税率 → 25% | $129.22 | 9.33% |
| 仅改 ERP → 地域加权 4.61% | $124.67 | 9.90% |
| **两项都改（现状）** | **$119.95** | **9.90%** |

税率贡献 −3.9%、ERP 贡献 −7.7%，合计 −10.8%。

### 配套：验证器的单元格解析器升级

ERP 现在是活公式（`=成熟基准 + 加权CRP`），而验证器原先只认**单格引用**（`=B48`），
读到算式就会抛 `could not convert string to float`。已扩展为能解析一层四则运算并递归取值。

> 加权 CRP 刻意写成显式乘加 `=B120*D120+B121*D121+…` 而不是 `SUMPRODUCT` ——
> 后者的区间语法（`:` 与 `,`）超出那个小解析器的范围。**让验证器读得懂，比公式短一点重要。**
